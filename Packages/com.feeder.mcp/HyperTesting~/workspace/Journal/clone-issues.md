# Clone issues

Problems while creating, launching, refreshing, compiling or stopping clone editors.
`[auto]` lines are written by the pool; agents add full entries below them.

Entry format:

```
### <yyyy-MM-dd HH:mm> - <who> - <clone or "orchestrator"> - <run id>
- What happened:
- Evidence:
- RAM at the time:
- Workaround used:
- Suggested Matrix fix:
```

Mark anything that wrote into the original project as **CRITICAL**.
